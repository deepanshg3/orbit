# Contributing to Orbit

Thank you for your interest in contributing to Orbit.

Orbit is an open-source project exploring autonomous AI systems for social media growth.

---

# Development Setup

1. Clone the repository

```
git clone https://github.com/deepanshg3/orbit.git
```

2. Navigate to the project folder

```
cd orbit
```

3. Install dependencies

Instructions will be added as development begins.

---

# Contribution Process

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Submit a pull request

---

# Branch Naming Convention

Use descriptive branch names.

Examples:

```
feature/trend-engine
feature/content-generator
feature/twitter-integration
bugfix/analytics-bug
```

---

# Commit Message Guidelines

Write clear commit messages.

Examples:

```
Add trend detection module
Improve tweet generation prompt
Fix analytics data parsing
```

---

# Code Guidelines

Contributors should aim for:

* clean and readable code
* clear documentation
* modular architecture
* descriptive variable names

---

# Reporting Issues

If you find a bug or want to suggest improvements:

1. Open an issue
2. Provide clear description
3. Include steps to reproduce the problem

---

Thank you for helping improve Orbit.

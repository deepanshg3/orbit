# Orbit Agent Architecture

Orbit uses a multi-agent architecture where each agent performs a specific task.

---

# Trend Agent

Purpose:

Identify emerging topics and narratives from external data sources.

Inputs:

Google Trends
Reddit discussions
Technology news feeds

Outputs:

Trending topics
Narrative clusters

---

# Strategy Agent

Purpose:

Decide what type of content should be created based on detected trends.

Responsibilities:

Select topics
Choose content format
Define posting schedule

Outputs:

Content strategy
Tweet ideas

---

# Content Agent

Purpose:

Generate tweets and threads.

Capabilities:

Generate hooks
Write tweet threads
Align messaging with brand voice

Outputs:

Tweet content
Thread structures

---

# Brand Guard Agent

Purpose:

Ensure generated content follows brand identity guidelines.

Checks:

Tone consistency
Messaging alignment
Content quality

---

# Analytics Agent

Purpose:

Collect performance metrics from Twitter posts.

Metrics collected:

Likes
Retweets
Replies
Impressions

---

# Learning Agent

Purpose:

Analyze analytics data to improve future strategies.

Example insights:

Which hooks perform best
Which topics generate engagement
Optimal posting times

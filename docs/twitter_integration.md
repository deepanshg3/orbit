# Twitter Integration

Orbit uses Twitter as the initial social media platform for publishing content.

---

# Posting Strategy

To stay within free API limits, Orbit posts approximately two tweets per day.

Typical schedule:

Morning post: Insight tweet
Evening post: Thread

---

# Publishing Workflow

Content Generated
↓
Tweet Queue
↓
Scheduler
↓
Twitter API
↓
Tweet ID Stored
↓
Analytics Tracking

---

# Data Stored

Each tweet record contains:

Tweet ID
Timestamp
Topic
Tweet content
Engagement metrics

This information is used by the analytics engine.

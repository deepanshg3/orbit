# Analytics Engine

The analytics engine measures the performance of tweets published by Orbit.

---

# Metrics Collected

Orbit tracks several engagement metrics.

Likes
Retweets
Replies
Impressions
Follower growth

---

# Data Storage

All analytics data is stored in a database.

Each tweet record contains:

Tweet ID
Topic
Hook type
Timestamp
Engagement metrics

---

# Learning Loop

The analytics engine feeds data into the learning engine.

The learning engine identifies patterns such as:

Which hooks generate the most engagement
Which topics perform best
Optimal posting times

These insights help Orbit improve future strategies.
